# Kicks Store - React E-Commerce App

A fully functional frontend e-commerce store with a working shopping cart.

## 🚀 Live Demo
[Click here to view the live app](https://sneaker-store-6q0ogwhxw.vercel.app)

## 🛠️ Tech Stack
- **Frontend:** React, Vite, CSS

## ✨ Features
- Browse a grid of products
- Add items to a slide-out shopping cart
- Remove items from the cart
- Calculate total price dynamically
- Mock checkout functionality
